# Mohammad-akhavan-official-website
Live Website:
https://mohammadakhavan.com

An official music website for Mohammad Akhavan, an Iranian singer, featuring his music, music videos, and artist information.

Designed and developed by Kasra Haghighi.

# Features
• Responsive and modern UI
• Videos playback using Plyr.js
• Dark and light theme
• Theme preference saved with LocalStorage
• Notification are using SweetAlert2
• SEO optimization
• Mobile-friendly design

# Technologies & Tools
• HTML5
• CSS3
• JavaScript
• Plyr.js
• SweetAlert2
• Font Awesome
